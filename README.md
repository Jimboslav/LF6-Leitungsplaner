# LF6 Leitungsplaner

Interaktive Streamlit-App zu den Teilen 6 bis 9 der Formelsammlung LF6 (Version 1.0.1):

- Leitungsdimensionierung mit Korrekturfaktoren und automatischer Querschnittsauswahl
- Prüfung von Schutzorganen nach Bemessungsstrom- und Auslöseregel
- Leiterwiderstände und Temperaturkorrektur
- Spannungsfall, Leitungsverluste und mittlerer Leistungsfaktor

## Start

```powershell
python -m pip install -r requirements.txt
streamlit run streamlit_app.py
```

Die App ist eine didaktische Planungshilfe. Für reale Anlagen sind die aktuellen Normen, Herstellerdaten und örtlichen Bedingungen maßgeblich.
